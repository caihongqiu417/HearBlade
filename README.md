# HearBlade
《HearBlade》是一款以音乐节奏为核心特色的类魂动作 RPG。玩家将在充满危险与未知的世界中探索、战斗并逐步成长，通过观察敌人的动作、聆听攻击节拍，在关键时刻完成攻击、格挡和闪避。
