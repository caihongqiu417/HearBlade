# 二阶段转换：本轮可测试版本

## 进入方式

正常战斗中血量首次降至 60% 以下只提出转阶段请求。下一次近战接触判定成功格挡/反击时，混合进入 Boss 专用 Taunt 完整动作。不会要求等待原连招播完再待机变色。

如果 10 秒内一直没有适合的接触，等当前已承诺连招完成后进入完整蓄势过渡，不取消半途攻击，也不会一直卡在一阶段。

## 演出

- 从当前游戏视角连续进入交锋近景，再退到能看清形态的三分之四视角，最后用 0.45 秒混合回原视角。
- HUD 约 0.29 秒淡出；回场约 0.5 秒淡入，二阶段轨道轻微上移入场。音符时间仍来自原 BeatClock。
- Taunt 使用现有动作的 Boss 专用副本。161 个骨骼的顺序、参考姿态及父子层级均核对相同，原动画未改。
- 肩背火焰与五枚原武器材质的悬浮刃冠渐次展开。已撤掉曾测试的建筑金环和暗钢金环，未继续使用它们。
- 安全时体型增长 10%，按胶囊高度补偿脚底位置；扩张会碰撞时保持原体型。未修改基础蓝图或关卡缩放。
- 爆发对齐约六拍后的最近小节首拍，之后两拍结束。场景节拍构件在该重拍做一次略强的响应。不启用新的音乐慢放；接入时清理旧的临时慢放，阶段请求期间屏蔽旧的末击慢放，不做全局慢动作。
- 输入只在演出期间锁定，历史/缓存输入不带入回场；血量、Combo、共鸣不因演出被重置。

本轮使用已有挑衅动作与防御动作衔接，并不是新制作的双人动作捕捉。披风跟随原动作与模拟，尚没有专门制作“展开披风”的骨骼动画。刃冠是形态轮廓的新增部分，不是换了一套完整 Boss 网格。

## 快速亲测

关闭已有游戏测试窗口，在项目 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Scripts\TestBossAscension.ps1
```

这只启动独立测试进程，在第六秒把 Boss 降到阶段阈值，不自动操作主角，不保存到关卡。随后亲自格挡或反击即可触发；一直闪避则验证无拼刀过渡。关闭测试窗口即退出。

正常打开原地图 PIE 无自动降血，需要实际打到阈值。

重点观察：交锋到动作是否自然、近景是否清楚、刃冠是否有压迫感但不挡读招、回场 UI 是否顺滑、回场后移动/闪避/格挡是否马上恢复。
