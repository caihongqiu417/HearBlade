# 刀光阅读与站位原型

## 玩家读招

判定轨道只显示落点时间。Boss 的姿态、刀光形状和声音表达招式；地面危险圈表达空间范围。刀光同时有三档压力，弱、中、强按本击伤害自动选择，分别改变世界空间提示的大小、刀刃轮廓亮度和近刀光晕。颜色不是唯一信号。

| 世界线索 | 当前含义 | 可用动作 |
| --- | --- | --- |
| 短促浅色刀芒 | 普通近战接触 | 短格挡；精准短格挡削减 Boss 韧性；也可闪避或走出刀路 |
| 扩张的深红宽弧、加速脉动的刀刃光晕、贴地的窄红刀路 | 只能闪避，格挡会失败 | 提前辨认刀路，闪避或走出实际刀路 |
| 宽青色弧线 | 宽刀路，但攻击数据允许格挡 | 观察挥刀方向，闪避、格挡或找侧面安全位 |
| 金色交叉刀芒 | 反击窗口 | 按现有反击键，在拍点回应 |
| 持续蓝色弧线 | 持续压刀 | 按住现有格挡键，跟随连续拍点并在尾拍释放 |
| 地面红圈 | 范围爆发 | 离开实际伤害半径；按原范围规则结算 |

两阶段都从本次实际指令产生刀光。普通浅色刀刃在两阶段均允许闪避或格挡；只能闪避、反击和持续格挡保留各自的独立判定。短格挡和招架仍是同一个操作，精准格挡额外削减 28 点 Boss 韧性。

两阶段使用同一条较小的节拍轨道。普通刀击、只能闪避和反击都只用同一种中性刀痕标落点，不在轨道上编码操作。持续格挡例外，保留蓝色按住区间、起点和金色释放端点。玩家从 Boss 身上的线索决定动作，从轨道读取精确时机与长按结束点。
反击提示在 Boss 刀刃附近显示放大的金色交叉刀光和画面空间内的漫画交叉斩，并播放独立的金属反击音。镜头在反击前轻微收紧并聚焦刀刃；成功反击时短促推近。只能闪避的危险刀路出现时镜头稍拉开，成功闪避时镜头侧移并拓宽视野。以上镜头幅度受近身遮挡保护和无障碍镜头震动设置约束。

深红贴地刀路只在必须闪避的刀刃攻击前出现，沿 Boss 当前目标方向延伸；Boss 锁定出刀方向后，它也停止追踪玩家。其宽度按危险刀路设置，不把整个竞技场染红。

## 走位收益

Boss 逐击 Motion Warping 在命中前 `StrikeCommitLeadSeconds`（默认 0.45 秒）固定目标，其余前摇仍会追踪玩家。刀刃未实际接触时，纯走位不再产生防御 `MISS`；主动闪避仍按已有节奏窗口判定。提前接触后若玩家明显移开，则不保留旧位置的命中锁存。

玩家在锁定刀路后横向移动至少 65 厘米、仍在 Boss 320 厘米内且没有按闪避，若该击落空，开放两拍侧移破绽。该破绽用 Boss 刀上的青色短光表示；从 Boss 的侧面或背面命中的轻/重攻击获得 1.5 倍伤害与共鸣收益。远距离跑开不产生此破绽。现有连段间隙和收招收益仍有效。

## 调整与验证

- 每个攻击数据可关闭 `bCommitStrikeDirection` 或调整 `StrikeCommitLeadSeconds`。每击 `Recognition` 可单独调 `BladeCueScale`、`BladeCueIntensity`、形状、颜色与提示声音。
- 在编辑器分别试正面短格挡、精准短格挡、侧移避刀、侧面追击、远离刀路、连续压刀和二阶段范围击。重点检查：刀光比判定轨道先引起注意；侧移确实在刀路外；走位落空不显示 `MISS`；格挡/闪避仍可靠；侧移破绽不会在正面或远处发奖。
- 代码编译及现有攻击时间测试可自动验证；姿态与刀光阅读性、数值手感仍需在实际镜头下试玩调整。
