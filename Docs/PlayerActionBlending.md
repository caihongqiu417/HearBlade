# 玩家动作衔接

角色在 BeginPlay 使用 `UPlayerCombatAnimInstance`。移动混合空间持续更新，动作通过 DefaultSlot 的动态 Montage 播放；不再在动作之间调用 PlayAnimation 切换到单节点模式。

- 动作切入：0.10 秒；切回移动：0.18 秒。
- 攻击、格挡动作末尾保留 0.10 秒视觉衔接余量；翻滚不延长。
- 新动作接替尚未退出的动作；没有新操作时才淡出到移动层。
- 输入缓冲、评分、无敌帧和位移仍由节奏战斗组件处理，不依赖 Montage 混合权重。
- 普通格挡允许点按；持续格挡仍使用真实按住状态。点按抬剑至少展示 0.22 秒，下一操作可接替。
- BAD 不再强制替换成受击动画。

这不自动生成新的连击招式，也不删除原始动画内部已有的收剑动作。若同一个攻击动画自身收剑很早，仍需进一步配置动画衔接区间或提供连续攻击素材。

自动测试：`HearBlade.Combat.InputTransitions` 与 `HearBlade.Combat.AnimationBlend`。后者检查真实骨骼姿势变化、攻击与格挡权重重叠，以及回到移动层。自动测试不代替最终视觉手感验收。
