# Boss 战斗设计备忘

## 远距离追击并卡拍进攻

当 Boss 与主角距离较远时，Boss 可以加速接近，或闪现到主角前方，并让到位后的攻击命中音乐拍点，使战斗保持紧凑、爽快。

后续实现时需要考虑：按距离选择追击方式；闪现落点避开障碍和与主角重叠；给玩家可读的动作预兆；根据目标拍点倒推移动、闪现与起手时间，并在拍点赶不上时顺延到下一可用拍。

## 战斗定位与阶段构想（2026-09-26）

HearBlade 的核心是近身拼刀与音乐节奏。Boss 的近战连段主要由玩家读招后闪避、格挡、反击来应对；WASD 负责调整站位、追击敌人，以及躲避范围攻击。近战后续击不应被设计成必须靠不断跑出攻击范围才能解决。

- 一阶段：下方指令 UI 辅助玩家熟悉节拍、操作与 Boss 连招。
- 二阶段：下方 UI 不再直接给出闪避、格挡、反击指令，只保留节拍圆圈。玩家通过 Boss 姿态、起手动作与刀光颜色识别操作。
- 三阶段：Boss 偶尔使用“夺视”技能，短时大幅限制视野。玩家依靠刀光、BGM 和简略 UI 继续读招与卡拍；受限期间仍需保留可辨认的攻击信息。三阶段的大部分时间保持正常视野。
- 主角共鸣值蓄满后可主动开启共鸣形态。参考《Hi-Fi Rush》的输入手感：玩家随时可以主动按键出招，动作表现与音乐节拍协调；恰好在拍点附近输入时获得额外收益。玩家用 WASD 追击和调整身位，主动维持攻势。具体输入窗口、攻击衔接和加成数值待定。
- Boss 将加入范围攻击。玩家可通过移动结合闪避离开危险区；若恰好在目标拍点附近脱离，额外获得共鸣值。普通脱离也能躲开伤害，判定窗口与共鸣奖励数值待定。

设计原则：空间移动服务于站位和范围招，近身交锋服务于读招与节拍操作；共鸣形态让玩家从应对 Boss 节奏转为主导进攻。以上为后续设计方向，不表示这些阶段和机制已经接入游戏。
