HearBlade：主角组件、输入与蓝图界面

主角的入口是 AHearBladeCharacter。它创建身体、镜头和玩法组件，保留蓝图能够调用的移动、视角与闪避函数。按键绑定、握剑校准和移动动画计算分别由独立组件处理。先看角色创建了哪些组件，再沿着一次输入进入战斗组件，比从头阅读所有动画计算更容易理解整个项目。

主角的组成

类 负责的内容 主要函数
AHearBladeCharacter 创建组件、提供移动入口、安排身体更新顺序 SetupPlayerInputComponent、DoMove、Tick
UHearBladeInputComponent 绑定输入、选择鼠标的攻击或防御操作、失去控制时清理输入 Bind、MousePrimaryCombatPressed、UpdateHeldActions、Unbind
UPlayerAttackComponent 轻重攻击、连招缓冲、攻击位移和命中结算 RequestAttack、RequestResonance
UPlayerDefenseComponent 防御窗口、格挡、弹反、闪避与受击状态 IsDefenseInputWindowOpen、RequestBlock、RequestParry、RequestDodge
UPlayerWeaponComponent 校准握持角度，更新剑的朝向 Initialize、Calibrate、UpdateDirection
UPlayerLocomotionComponent 根据实际速度选择步行、跑步和追击姿态 Initialize、MeasureSpeeds、Update
UBossCombatCameraComponent 锁定目标与战斗镜头 ToggleLockOn、GetCombatTarget

这些组件属于同一个角色，各自保存完成职责所需的状态。输入组件保存按住了哪个键，武器组件保存校准后的握持角度，移动动画组件保存平滑后的采样位置。攻击是否允许、是否进入连招窗口，仍由战斗组件决定。

攻击、防御与输入窗口

UPlayerAttackComponent 负责出招，UPlayerDefenseComponent 负责防御和受击恢复。角色、输入和武器组件分别通过 AttackComponent、DefenseComponent 保存引用。蓝图中原有组件实例名保留为 BeatAttack、RhythmCombat，已保存的参数仍挂在原来的实例上。

输入入口统一使用 Request，例如 RequestAttack、RequestBlock、RequestParry、RequestDodge。返回 true 表示请求已经接收，可能立即执行，也可能等待缓存；不表示已经命中或防御成功。RequestResonance 接收后等待下一小节启动共鸣。

机制 代码位置 处理规则
普通攻击缓存 RequestAttack、TickComponent 空闲但尚未恢复时，保留第一次输入，最多等待 1 秒游戏时间，重复按键不延长期限
连招输入缓存 RequestAttack、TickAttack 当前攻击中保留第一次轻重选择，按原始音乐时间评级，到下一击起手时刻才执行
接招截止 LatestCueAudio + ChainLateSeconds() 截止后拒绝连招输入，收招动画结束不等于连招窗口关闭
攻击命中窗口 SweepBlade 在目标音乐时刻前后各 40 毫秒内检查武器轨迹，经过窗口还要实际接触并通过遮挡检查
防御输入窗口 IsDefenseInputWindowOpen 根据附近敌人预警决定鼠标左右键用于攻还是防，不直接判定防御成功
防御缓存 BufferDefenseInput、ProcessDefenseBuffer 只保留最新操作，按游戏时间过期；受击锁定时至少保留到解锁后 0.05 秒
缓存期间松开格挡 ReleaseBlock、ProcessDefenseBuffer 保存原始松键时间，缓存执行后补上释放，避免一直举盾
闪避无敌时间 IsInvulnerable 从原始按键的音乐时间计算，缓存等待不会额外延长无敌
防御评级 ResolveDefenseResult、ConsumeClosestDefenseInput 从按键历史取出最接近理想时刻的一次，使用后移除，不能重复抵挡后续命中

攻击的音乐时间用于安排起手、命中和接招，游戏时间用于缓存过期和受击恢复。实际命中、输入评级、动画播放是三个独立判断，不用“动画还在播放”代替是否可以接招或是否无敌。

按一次鼠标左键

玩家取得角色控制权后，UE 调用角色的 SetupPlayerInputComponent。角色把引擎创建的输入组件交给 PlayerInput->Bind。Bind 登记 IA 的回调，并把战斗按键映射加入本地玩家的 Enhanced Input 子系统。

鼠标左键触发 MousePrimaryCombatPressed。它先向玩家防御组件询问当前是否处于鼠标防御窗口：窗口内调用 RequestParry，窗口外调用 RequestAttack(Light)。输入组件只选择入口，攻击组件再决定立即开始攻击、保存到连招缓冲，还是拒绝这次操作。

右键同样区分窗口内格挡和窗口外重击。bMouseSecondaryHeld 表示右键仍按着，bMouseSecondaryOwnsBlock 表示这次右键已经启动了格挡。玩家提前按住右键时，UpdateHeldActions 会在窗口出现后尝试格挡；松开时只结束右键自己启动的格挡。

失去角色控制权时，UnPossessed 调用 Unbind。它结束按住操作，清掉自己的回调和临时映射。回调使用登记时保存的句柄逐个删除，因此不会清空其他组件或蓝图添加的输入。再次控制角色时重新绑定，原有临时 IA 对象继续使用。

基础移动和视角动作仍保存在角色蓝图的原字段中，避免丢失已经配置的资源引用。战斗 IA 沿用原来的运行时创建方式，按键读取 URhythmCombatInputSettings；这次没有把它们全部改成内容浏览器中的资源。

移动、朝向和握剑

DoMove 先保存玩家希望移动的方向，再检查当前动作是否限制移动。允许移动时，以镜头的水平朝向计算前方和右方，交给 CharacterMovement。攻击期间的速度比例仍从攻击组件读取。

每帧身体更新保持以下顺序：检查持续按住的右键、检查角色是否死亡、校准握剑、更新角色朝向、更新剑的朝向、更新移动动画。新的武器和移动动画组件没有独立 Tick，而是由角色在原来的位置调用，避免拆分后改变执行先后。

攻击和防御时，剑跟随右手动画，并加上初始化时记录的握持偏移。普通移动时，剑保持朝向角色前方。SyncAttackWeapon 仍是攻击组件可调用的入口，在命中检测前及时同步剑的朝向。武器组件不结算伤害，也不修改攻击窗口。

移动动画组件读取实际速度，并把速度换算成混合空间的采样半径。步行、跑步和快跑的参考速度来自动画根节点的位移；原地动画无法测量时使用已有默认值。锁定目标后，只有玩家确实朝远处目标移动，才进入追击姿态。进入和退出追击使用不同阈值，避免在临界距离反复切换。

角色蓝图中的 FreeRunSpeed、LockedCombatWalkSpeed、握剑偏移和插值速度仍保留原名和原位置。移动计算也保留原规则：锁定步行速度不低于 280，追击速度是自由移动速度的 1.3 倍。仅在拆分职责时顺便改变这些数值，会让原有动画和手感发生变化。

蓝图界面与 MVC

ARhythmCombatHUD 创建 /Game/UI/MVC/WBP_RhythmCombatHUD，把它和 URhythmWidgetController 连接起来。处理器读取角色和 Boss 的状态，整理成 FRhythmHUDViewModel，再通知界面。UMG 蓝图继续负责布局和显示，不需要迁移到 C++ 绘制。

触控控件也由 HUD 创建和销毁。PlayerController 保留原蓝图中的触控控件类型和平台配置，HUD 读取这些配置；控制器不再亲自创建控件。死亡后按回车通过 Restart IA 进入界面处理器的 RestartLevel，处理器确认本机角色已经死亡后才重开当前关卡，不再由角色 Tick 轮询回车键。

节拍轨道的位置每帧都在变化，因此原来的显示更新仍然保留。MVC 的作用是让读取玩法数据和修改控件各有归属，不是把所有连续变化都强行改成事件。

长绑定函数按准备组件、基础操作、鼠标攻防、独立战斗按键和启用映射分段，内部注释解释每一步的目的

源码：Input/HearBladeInputComponent.cpp

void UHearBladeInputComponent::Bind(UInputComponent* Input, UInputAction* Jump, UInputAction* Move,
                                  UInputAction* Look, UInputAction* MouseLook)
{
    if (!Input || BoundInput.Get() == Input) return;
    // 更换输入组件前先清理旧绑定和按住状态
    Unbind();
    Character = Cast<AHearBladeCharacter>(GetOwner());
    auto* Enhanced = Cast<UEnhancedInputComponent>(Input);
    if (!Character || !Enhanced)
    {
        UE_LOG(LogHearBlade, Error, TEXT("%s：角色输入需要 EnhancedInputComponent"), *GetNameSafe(GetOwner()));
        return;
    }
    // 保存操作要调用的组件，按键触发时直接转交
    RhythmCombat = Character->FindComponentByClass<UPlayerDefenseComponent>();
    BeatAttack = Character->FindComponentByClass<UPlayerAttackComponent>();
    CombatCamera = Character->FindComponentByClass<UBossCombatCameraComponent>();
    BoundInput = Input;
    CreateCombatActions();
    // 记录每次绑定的句柄，失去控制时只删除自己的回调
    const auto BindAction = [this, Enhanced](UInputAction* Action, ETriggerEvent Event, auto Callback)
    {
        if (Action) BindingHandles.Add(Enhanced->BindAction(Action, Event, this, Callback).GetHandle());
    };
    // 基础操作沿用角色蓝图的 IA，跳跃区分按下和松开
    BindAction(Jump, ETriggerEvent::Started, &UHearBladeInputComponent::JumpStarted);
    BindAction(Jump, ETriggerEvent::Completed, &UHearBladeInputComponent::JumpEnded);
    // 移动松开或取消时也发送零输入，避免保留上一次方向
    BindAction(Move, ETriggerEvent::Triggered, &UHearBladeInputComponent::Move);
    BindAction(Move, ETriggerEvent::Completed, &UHearBladeInputComponent::Move);
    BindAction(Move, ETriggerEvent::Canceled, &UHearBladeInputComponent::Move);
    BindAction(MouseLook, ETriggerEvent::Triggered, &UHearBladeInputComponent::Look);
    BindAction(Look, ETriggerEvent::Triggered, &UHearBladeInputComponent::Look);

    // 战斗按键只转交意图，动作条件和输入缓冲仍由战斗组件处理
    BindAction(LockOnAction, ETriggerEvent::Started, &UHearBladeInputComponent::ToggleCombatLock);
    BindAction(DodgeAction, ETriggerEvent::Started, &UHearBladeInputComponent::Dodge);
    // 鼠标需要区分攻防窗口，右键还需要记录按住和松开
    BindAction(MousePrimaryCombatAction, ETriggerEvent::Started, &UHearBladeInputComponent::MousePrimaryCombatPressed);
    BindAction(MouseSecondaryCombatAction, ETriggerEvent::Completed, &UHearBladeInputComponent::MouseSecondaryCombatReleased);
    BindAction(MouseSecondaryCombatAction, ETriggerEvent::Canceled, &UHearBladeInputComponent::MouseSecondaryCombatReleased);
    BindAction(MouseSecondaryCombatAction, ETriggerEvent::Started, &UHearBladeInputComponent::MouseSecondaryCombatPressed);
    // 手柄和独立按键直接发起对应动作，格挡松开时结束防御
    BindAction(LightAttackAction, ETriggerEvent::Started, &UHearBladeInputComponent::LightAttack);
    BindAction(HeavyAttackAction, ETriggerEvent::Started, &UHearBladeInputComponent::HeavyAttack);
    BindAction(ResonanceAction, ETriggerEvent::Started, &UHearBladeInputComponent::ActivateResonance);
    BindAction(BlockAction, ETriggerEvent::Started, &UHearBladeInputComponent::BlockStarted);
    BindAction(BlockAction, ETriggerEvent::Completed, &UHearBladeInputComponent::BlockEnded);
    BindAction(BlockAction, ETriggerEvent::Canceled, &UHearBladeInputComponent::BlockEnded);
    BindAction(CounterAction, ETriggerEvent::Started, &UHearBladeInputComponent::Counter);
    BindAction(RestartAction, ETriggerEvent::Started, &UHearBladeInputComponent::RestartPressed);

    // 回调绑定完成后，再启用本机玩家的按键映射
    if (auto* Player = Cast<APlayerController>(Character->GetController()))
    {
        InputSubsystem = ULocalPlayer::GetSubsystem<UEnhancedInputLocalPlayerSubsystem>(Player->GetLocalPlayer());
        if (InputSubsystem.IsValid())
        {
            InputSubsystem->AddMappingContext(LockOnMapping, 1);
            InputSubsystem->AddMappingContext(DodgeMapping, 2);
            InputSubsystem->AddMappingContext(DefenseMapping, 2);
        }
    }
}

void UHearBladeInputComponent::MousePrimaryCombatPressed()
{
	const bool Defense = RhythmCombat && RhythmCombat->IsDefenseInputWindowOpen();
	UE_LOG(LogTemp, Display, TEXT("MouseCombat: LMB -> %s"), Defense ? TEXT("COUNTER") : TEXT("LIGHT"));
	if (Defense)
		Counter();
	else
		LightAttack();
}

离开角色时按原绑定记录清理，只移除自己的回调和映射

源码：Input/HearBladeInputComponent.cpp

void UHearBladeInputComponent::Unbind()
{
	// 先结束按住操作，避免重新控制角色后仍保持格挡或跳跃
    if ((bBlockHeld || bMouseSecondaryOwnsBlock) && RhythmCombat) RhythmCombat->ReleaseBlock();
    bBlockHeld = bMouseSecondaryOwnsBlock = bMouseSecondaryHeld = false;
    if (Character)
    {
        Character->DoMove(0.f, 0.f);
        Character->StopJumping();
    }
    // 只清除本组件登记的回调，保留其他系统的输入
    if (auto* Enhanced = Cast<UEnhancedInputComponent>(BoundInput.Get()))
        for (uint32 Handle : BindingHandles) Enhanced->RemoveBindingByHandle(Handle);
    BindingHandles.Reset();
    BoundInput.Reset();
    // 使用绑定时保存的子系统，角色失去控制后也能移除原来的映射
    if (InputSubsystem.IsValid())
    {
        InputSubsystem->RemoveMappingContext(LockOnMapping);
        InputSubsystem->RemoveMappingContext(DodgeMapping);
        InputSubsystem->RemoveMappingContext(DefenseMapping);
    }
    InputSubsystem.Reset();
}

void AHearBladeCharacter::Tick(float DeltaSeconds)
{
	Super::Tick(DeltaSeconds);
    PlayerInput->UpdateHeldActions();
    if (RhythmCombat && RhythmCombat->Health <= 0.f) return;
	CalibrateSwordGrip();
	UpdateCombatFacing(DeltaSeconds);
	UpdateSwordDirection(DeltaSeconds);
	UpdateKnightLocomotion(DeltaSeconds);
}

握剑校准记录剑与右手的相对旋转，后续攻击动画继续使用这个关系

源码：Combat/Player/PlayerWeaponComponent.cpp

void UPlayerWeaponComponent::Calibrate(float SwordGripVerticalOffsetCm)
{
	// 等待前两次骨骼更新，再校准一次握持角度
	if (!Character || bSwordGripCalibrated || !EquippedSword || ++SwordCalibrationFrames < 3)
		return;

	const FVector CurrentBladeDirection =
	    EquippedSword->GetComponentTransform().TransformVectorNoScale(FVector::YAxisVector).GetSafeNormal();
	const FVector DesiredBladeDirection = Character->GetActorForwardVector().GetSafeNormal();
	if (CurrentBladeDirection.IsNearlyZero() || DesiredBladeDirection.IsNearlyZero())
		return;

	const FQuat WorldCorrection = FQuat::FindBetweenNormals(CurrentBladeDirection, DesiredBladeDirection);
	EquippedSword->SetWorldRotation(WorldCorrection * EquippedSword->GetComponentQuat());
	EquippedSword->SetWorldLocation(EquippedSword->GetComponentLocation() +
	                                FVector::UpVector * SwordGripVerticalOffsetCm);
	const FQuat HandRotation = Character->GetMesh()->GetSocketTransform(TEXT("hand_r"), RTS_World).GetRotation();
	// 保存剑相对右手的角度，后续换动画时仍保持这个握持关系
	SwordGripRotationOffset = (HandRotation.Inverse() * EquippedSword->GetComponentQuat()).GetNormalized();
	bSwordGripCalibrated = true;

	const FVector CorrectedDirection =
	    EquippedSword->GetComponentTransform().TransformVectorNoScale(FVector::YAxisVector).GetSafeNormal();
	UE_LOG(LogTemp, Display, TEXT("SwordGrip: forward alignment dot=%.4f"),
	       FVector::DotProduct(CorrectedDirection, DesiredBladeDirection));
}

速度先对应步行圈，再过渡到跑步和快跑圈，采样范围始终限制在已有动画内

源码：Combat/Player/PlayerLocomotionComponent.cpp

float UPlayerLocomotionComponent::RadiusForSpeed(float Speed) const
{
	if (Speed <= WalkAnimSpeed)
		return WalkRadius * Speed / FMath::Max(WalkAnimSpeed, 1.f);
	if (Speed <= RunAnimSpeed)
		return WalkRadius +
		       (RunRadius - WalkRadius) * (Speed - WalkAnimSpeed) / (RunAnimSpeed - WalkAnimSpeed);
	if (FastRadius <= RunRadius)
		return RunRadius;
	return FMath::Min(FastRadius, RunRadius + (FastRadius - RunRadius) * (Speed - RunAnimSpeed) /
	                                              (FastAnimSpeed - RunAnimSpeed));
}
