# Texture provenance

`T_HC_Limestone_Detail.png` is an original image generated with the built-in imagegen tool on 2026-09-27, then copied into this project. It is used as the warm gray limestone base color for the arena paving and architecture. It is not an audio visualization texture.

Prompt: Production game material base-color texture, square, seamless tileable warm gray ivory limestone marble; orthographic flat scanned surface, mature ornate fantasy architecture, fine mineral grains, delicate sparse calcite veins, tiny irregular mineral inclusions, subtle layered stone mottling, medium light warm gray, low contrast, subdued saturation. Albedo only, uniform illumination, no baked highlights, cast shadows, perspective, borders, grout, objects, text, large cracks, or dramatic streaks.

The other HC color and roughness maps are baked from native Blender procedural materials through Blender MCP. No downloaded third-party model or texture pack is used. Model source and native editing/baking steps are preserved in the blend file and `Scripts/Art`.
